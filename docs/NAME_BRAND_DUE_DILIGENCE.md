# Project name and affiliation review

**Status: LAUNCH BLOCKER / development-only.** This project currently uses the name Independent Living Canada. An established federal nonprofit operates under the same name, Independent Living Canada / Vie Autonome Canada. This project is not affiliated with or endorsed by it.

## Verified facts (research dated 2026-11-27)
- Corporations Canada's official record lists Independent Living Canada / Vie Autonome Canada as active, corporation no. 238132-0, under the Canada Not-for-profit Corporations Act. Official record: https://ised-isde.canada.ca/cc/lgcy/fdrlCrpDtls.html?corpId=2381320&lang=eng
- Its official website describes its national mission as a nonprofit association/network of Independent Living Centres, run by and for people with disabilities, supporting the Independent Living philosophy: https://www.ilc-vac.ca/about
- The existing organization's activity, target audience, national scope and name are highly adjacent to our service concept. Name-confusion risk is therefore material; this is not a legal conclusion.
- Government guidance explains confusion assessment considers resemblance, services, geography, clientele, distinctiveness, and duration/recognition; it recommends discussion with the existing organization before a formal name-confusion process: https://ised-isde.canada.ca/site/corporations-canada/en/naming-corporation/what-do-if-corporate-name-can-be-confused-another-name-or-trademark
- Government guidance recommends Nuans and registry searches for similar corporate names and trademarks, and province/territory trade-name searches: https://www.canada.ca/en/services/business/start/choosing-a-business-name-2.html
- CIPO trademark database: https://ised-isde.canada.ca/cipo/trademark-search/srch?lang=eng

## Immediate controls
- Keep site in development pilot mode; no real service bookings.
- Pause new provider recruitment/promotional outreach under this name until reviewed.
- Continue monitoring replies to already-sent outreach; do not send new messages or follow-ups. If someone requests no contact, suppress.
- Preserve repository, website, database, research and project assets. Do not make a rebranding decision yet.
- Homepage and privacy page now carry a visible independent/non-affiliation and name-review notice.
- Do not state name is cleared, trademark-safe, or legally approved.
